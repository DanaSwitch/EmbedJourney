# 江科大STM32入门教程 详细学习笔记（贴合教程+重点突出）

说明：本笔记完全对应江科大STM32入门教程，以STM32F103系列（Cortex-M3内核）、标准库开发为核心，重点记录「教程高频考点+配置步骤+实战注意事项」，省略冗余理论，聚焦“能回忆、能复用、能对应教程案例”的核心内容，适配课后总结、知识点复盘需求。

# 1 基础知识（STM32入门核心铺垫，教程开篇重点）

## 1.1 STM32 简介

1.  系列划分：STM32按内核分为Cortex-M0/M3/M4/M7，教程重点讲「STM32F103系列」（Cortex-M3内核），属于入门款，性价比高，常用型号：STM32F103C8T6（最小系统板，48引脚）、STM32F103ZET6（开发板，144引脚）。

2.  核心硬件架构：

- 内核：Cortex-M3，负责执行指令，控制整个芯片的运行；

- 总线架构：AHB（高速总线，连接内核、FLASH、RAM）、APB1（低速总线，36MHz，连接TIM2-TIM7、USART2等）、APB2（高速总线，72MHz，连接GPIO、TIM1、USART1、ADC等）；

- 存储结构：片上FLASH（程序存储，F103C8T6为64KB）、片上SRAM（数据存储，F103C8T6为20KB），程序运行时，FLASH中的程序加载到SRAM中执行。

3.  引脚定义与功能：

- 通用IO口（GPIO）：大部分引脚可复用为其他外设功能（如PA9/PA10可复用为USART1的TX/RX）；

- 电源引脚：VCC（3.3V）、GND（地），注意不能接5V，否则烧毁芯片；

- 复位引脚（NRST）：低电平复位，正常工作时接高电平；

- 下载/调试引脚：SWD模式（PA13=SWDIO，PA14=SWCLK），JTAG模式（需更多引脚，教程主推SWD模式，简洁方便）。

## 1.2 STM32 基本硬件模块

1.  核心外设框架（按功能分类，贴合教程讲解顺序）：

- 通用外设：GPIO、EXTI、TIM、ADC、DMA、FLASH、看门狗、电源控制；

- 通信外设：USART、I2C、SPI、CAN；

- 辅助外设：SysTick（系统滴答定时器，用于延时）、时间戳。

2.  最小系统组成（教程重点，芯片正常工作的必备电路）：

- 电源电路：3.3V稳压电路（如AMS1117芯片），给芯片提供稳定3.3V电压；

- 复位电路：手动复位（按键）+上电复位，确保芯片正常启动；

- 时钟电路：外部晶振电路（8MHz晶振，配合电容），为芯片提供精准时钟；

- 下载接口：SWD接口（2根线），用于程序下载和在线调试。

## 1.3 STM32 时钟系统（★核心，所有外设配置前提，教程反复强调）

1.  时钟源分类（4个，教程重点讲HSI和HSE）：

- HSI：高速内部时钟，8MHz，精度低，无需外部元件，适合紧急启动；

- HSE：高速外部时钟，教程用8MHz（外部晶振），精度高，是系统时钟的主要来源；

- LSI：低速内部时钟，40kHz，主要用于独立看门狗（IWDG）；

- LSE：低速外部时钟，32.768kHz，用于实时时钟（RTC），教程未重点讲解。

2.  时钟树解析（核心逻辑：HSE→倍频→SYSCLK→分频→各外设时钟）：

- 系统时钟（SYSCLK）：F103最大为72MHz，教程配置为72MHz（8MHz HSE × 9倍频 = 72MHz）；

- AHB总线时钟：等于SYSCLK（72MHz）；

- APB1总线时钟：最大36MHz，由AHB分频得到（72MHz ÷ 2 = 36MHz）；

- APB2总线时钟：等于AHB时钟（72MHz）；

- 外设时钟：每个外设都有独立的时钟开关，配置外设前必须先“使能对应外设时钟”（教程高频易错点）。

3.  时钟配置方法（标准库函数，教程封装在sys.c中）：

- 步骤：使能HSE→等待HSE稳定→配置AHB/APB1/APB2分频系数→配置PLL（倍频器）→使能PLL→等待PLL稳定→将PLL作为系统时钟；

- 核心函数：SystemInit()（系统默认初始化，教程修改后适配72MHz）、RCC_APB2PeriphClockCmd()（使能APB2外设时钟）、RCC_APB1PeriphClockCmd()（使能APB1外设时钟）。

# 2 新建工程（Keil5为主，教程实战第一步，重操作+理文件）

## 2.1 工程新建一般步骤（Keil5 MDK-ARM，教程标准操作）

1.  新建工程：打开Keil5→Project→New μVision Project→选择保存路径、命名工程（如“LED”）→点击“Save”。

2.  芯片选型：在弹出的“Select Device for Target”窗口中，搜索“STM32F103C8T6”（或对应型号）→选中后点击“OK”→弹出“Manage Run-Time Environment”，直接点击“Cancel”（教程不使用MDK自带的库，用标准库）。

3.  工程目录搭建（江科大经典分层，便于管理，避免文件混乱）：

- Core：存放主函数（main.c）、系统相关文件（sys.c/h、delay.c/h、usart.c/h）；

- Startup：存放启动文件（.s文件）；

- Driver：存放外设驱动文件（如gpio.c/h、oled.c/h、tim.c/h）；

- Library：存放STM32标准库文件（核心文件，筛选后添加）。

4.  添加标准库文件（STM32F10x_StdPeriph_Lib）：

- 筛选核心文件：Library中添加“stm32f10x_core.c”（核心函数）、对应外设的库文件（如gpio相关的“stm32f10x_gpio.c”）；

- 添加头文件：将标准库的“inc”文件夹、工程各目录（Core、Driver等）添加到Keil5的头文件路径中。

5.  添加启动文件：根据芯片型号选择启动文件（教程重点），F103C8T6对应“startup_stm32f103xb.s”（xb对应中容量芯片，FLASH≤128KB），添加到Startup目录下。

6.  宏定义添加：在Keil5“魔术棒”→C/C++→Define中，添加“USE_STDPERIPH_DRIVER,STM32F10X_MD”（MD表示中容量芯片，对应C8T6），避免头文件报错。

7.  下载调试配置：

- 点击“魔术棒”→Debug→选择调试器（如“ST-Link Debugger”）→点击“Settings”；

- 切换到“Flash Download”选项卡→勾选“Reset and Run”（下载后自动复位运行）→选择烧录算法（“STM32F103C8”）→点击“OK”。

8.  新建主函数：在Core目录下新建“main.c”，添加基础框架（包含头文件、main函数），编译无报错即完成工程创建。

## 2.2 启动文件

1.  启动文件作用（教程核心讲解，芯片上电后首先执行的文件）：

- 初始化堆栈（定义堆栈大小，为程序运行分配内存）；

- 初始化中断向量表（所有中断的入口地址，如复位中断、外部中断）；

- 跳转到main函数（启动文件执行完初始化后，最终调用main函数，程序进入用户逻辑）。

2.  启动文件选型（对应芯片型号，教程重点区分）：

- 按芯片容量划分：

- 小容量（FLASH≤32KB）：startup_stm32f103x6.s；

- 中容量（FLASH 64KB~128KB）：startup_stm32f103xb.s（F103C8T6用此文件）；

- 大容量（FLASH≥256KB）：startup_stm32f103xe.s（F103ZET6用此文件）。

3.  启动文件核心代码解析（教程重点，无需逐行记住，理解关键部分）：

- 堆栈定义：Stack_Size（栈大小，默认0x400）、Heap_Size（堆大小，默认0x200）；

- 中断向量表：__Vectors，包含复位中断（Reset_Handler）、外部中断（EXTI0_IRQHandler）等入口；

- Reset_Handler：复位中断服务函数，内部调用SystemInit()（时钟初始化），然后跳转到main()。

## 2.3 江科大经典底层文件（★回忆重点，教程中封装的核心文件，可直接复用）

教程中封装了3个核心底层文件，几乎所有实战案例都需要用到，重点记忆函数功能，无需重复编写。

1.  sys.c/h（系统相关，时钟+位带操作）：

- 核心功能：重写SystemInit()，配置系统时钟为72MHz；实现位带操作（简化IO口操作）；

- 位带操作函数（高频使用）：

- PBout(n)：将PB口的第n位设置为输出高电平（如PBout(0)=1，PB0置1）；

- PBin(n)：读取PB口第n位的电平（如if(PBin(0)==1)，判断PB0是否为高）；

- 其他端口（PA、PC等）同理，函数名对应PAout、PAin等。

2.  delay.c/h（延时函数，精准延时）：

- 实现方式：基于SysTick定时器（系统滴答定时器，属于Cortex-M3内核外设）；

- 核心函数（直接调用）：

- delay_us(u32 nus)：微秒级延时（如delay_us(100)，延时100us）；

- delay_ms(u16 nms)：毫秒级延时（如delay_ms(500)，延时500ms）；

- 注意：延时函数不能在中断服务函数中使用（会导致中断阻塞）。

3.  usart.c/h（串口相关，调试必备）：

- 核心功能：初始化USART1，实现printf重定向（串口打印调试信息）、串口数据收发；

- 核心函数：

- uart_init(u32 bound)：串口初始化，参数为波特率（如uart_init(9600)）；

- printf(“xxx”)：串口打印（需包含stdio.h头文件）；

- uart_send_byte(u8 data)：发送一个字节数据；

- 注意：使用printf前，必须先调用uart_init()初始化串口。

## 2.4 工程创建注意事项（教程高频易错点，重点记忆）

1.  标准库版本匹配：必须使用STM32F10x系列的标准库，不能混用F4、F7系列的库，否则会报错。

2.  魔术棒配置常见错误：

- 头文件路径未添加：编译报错“no such file or directory”，需重新添加所有头文件所在目录；

- 宏定义未添加：报错“undefine identifier”，需添加USE_STDPERIPH_DRIVER和对应芯片容量的宏定义；

- 烧录算法选错：下载失败，需根据芯片型号选择正确的烧录算法（如C8T6对应STM32F103C8）。

3.  中文乱码：Keil5默认编码为GB2312，若添加中文注释乱码，需在“魔术棒”→Editor→Encoding中选择“GB2312”。

4.  文件命名规则：文件名不能包含中文、空格和特殊字符，否则编译或下载失败。

5.  启动文件选错：芯片无法正常启动，需根据芯片容量（小/中/大）选择对应的启动文件。

# 3 基本外设（按教程讲解顺序，重配置步骤+函数封装+实战应用）

## 3.1 GPIO（通用输入输出口，入门第一个外设，教程重点）

1.  GPIO工作模式（共8种，教程重点讲解4种常用模式）：

- 输出模式（2种）：

- 推挽输出（GPIO_Mode_Out_PP）：可输出高/低电平，驱动能力强（如驱动LED、蜂鸣器）；

- 开漏输出（GPIO_Mode_Out_OD）：只能输出低电平，高电平需外接上拉电阻（多用于I2C协议）；

- 输入模式（2种）：

- 上拉输入（GPIO_Mode_IPU）：默认电平为高，按键检测常用（避免电平漂浮）；

- 下拉输入（GPIO_Mode_IPD）：默认电平为低，较少使用；

- 其他模式（复用推挽/开漏、浮空输入）：后续外设（如USART、SPI）复用IO时使用。

2.  标准库配置步骤（固定4步，所有外设配置的通用思路，教程反复强调）：

步骤1：使能GPIO对应总线时钟（GPIO属于APB2外设，用RCC_APB2PeriphClockCmd()）；

步骤2：定义GPIO初始化结构体（GPIO_InitTypeDef GPIO_InitStructure）；

步骤3：配置结构体参数（引脚、模式、输出速度）；

步骤4：调用GPIO_Init()函数，完成初始化。

3.  核心函数与参数配置：

- 时钟使能函数：RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE); // 使能GPIOA时钟

- 结构体参数：

- GPIO_Pin：指定要配置的引脚（如GPIO_Pin_0、GPIO_Pin_0|GPIO_Pin_1，多个引脚用“|”连接）；

- GPIO_Mode：配置工作模式（如GPIO_Mode_Out_PP、GPIO_Mode_IPU）；

- GPIO_Speed：输出速度（仅输出模式有效，GPIO_Speed_50MHz即可，教程默认配置）。

- 常用操作函数：

- GPIO_SetBits(GPIOA, GPIO_Pin_0); // 将GPIOA_PIN_0置高电平

- GPIO_ResetBits(GPIOA, GPIO_Pin_0); // 将GPIOA_PIN_0置低电平

- GPIO_ReadInputDataBit(GPIOA, GPIO_Pin_0); // 读取GPIOA_PIN_0的输入电平

4.  实战应用（教程经典案例）：

- LED闪烁：配置GPIO为推挽输出，用delay_ms()延时，循环调用SetBits和ResetBits；

- 按键检测：配置GPIO为上拉输入，读取引脚电平，判断按键是否按下（需消抖，用delay_ms(20)）；

- 蜂鸣器驱动：配置GPIO为推挽输出，输出高低电平控制蜂鸣器发声。

5.  易错点：配置输入模式时，忘记设置上拉/下拉，导致引脚电平漂浮，检测结果不稳定。

## 3.2 OLED（基于I2C/SPI，教程中重点实战外设，重驱动封装）

教程主推「0.96英寸OLED屏」，重点讲解软件I2C驱动（无需依赖硬件I2C外设，通用性强），SPI版作为拓展。

1.  OLED硬件连接（软件I2C模式，4根线，教程标准连接）：

- VCC：3.3V（不能接5V，否则烧毁OLED）；

- GND：地（与STM32共地，否则通信失败）；

- SCL：时钟线，接STM32任意GPIO（教程用PB0）；

- SDA：数据线，接STM32任意GPIO（教程用PB1）。

2.  核心思路：OLED驱动本质是“通过I2C协议向OLED控制器（如SSD1306）发送指令和数据”，教程封装为oled.c/h，直接调用函数即可。

3.  驱动文件核心函数（教程封装，重点记忆用法）：

- OLED_Init(void)：OLED初始化，程序开头调用，完成OLED启动配置；

- OLED_Clear(void)：清屏，清除OLED上所有显示内容；

- OLED_ShowChar(u8 x, u8 y, u8 chr)：在指定位置（x列，y页）显示一个字符（如'A'、'0'）；

- OLED_ShowString(u8 x, u8 y, u8 *str)：在指定位置显示字符串（如"STM32 OLED"）；

- OLED_ShowNum(u8 x, u8 y, u32 num, u8 len)：在指定位置显示数字（num为数字，len为数字位数）；

- OLED_ShowChinese(u8 x, u8 y, u8 no)：显示汉字（需提前添加汉字字模，教程提供字模生成方法）。

4.  软件I2C底层函数（封装在oled.c中，无需修改，理解原理即可）：

- I2C_Start(void)：发送I2C起始信号（SCL高电平时，SDA从高变低）；

- I2C_Stop(void)：发送I2C停止信号（SCL高电平时，SDA从低变高）；

- I2C_SendAck(u8 ack)：发送应答信号（0为应答，1为非应答）；

- I2C_WaitAck(void)：等待应答信号；

- I2C_SendByte(u8 dat)：发送一个字节数据；

- I2C_ReadByte(void)：接收一个字节数据。

5.  实战应用：

- 显示系统信息：如“STM32 TEST”、芯片时钟频率；

- 显示外设数据：如按键状态（“KEY: ON/OFF”）、ADC采集的电压值；

- 显示调试信息：替代串口打印，直观查看程序运行状态。

6.  易错点：OLED不显示，大概率是硬件连接错误（SCL/SDA接反、未共地）或初始化函数未调用。

## 3.3 EXTI（外部中断/事件控制器，实现外部信号触发中断）

1.  EXTI基本原理（教程重点讲解中断功能，事件功能略过）：

- EXTI可管理19个中断线，其中16个对应GPIO口（EXTI0对应PA0~PG0，EXTI1对应PA1~PG1，以此类推）；

- 每个中断线可配置触发方式（上升沿、下降沿、双边沿）；

- 中断触发后，需配置NVIC（嵌套向量中断控制器），才能执行中断服务函数。

2.  核心概念：NVIC（嵌套向量中断控制器）

- 作用：管理所有中断的优先级，决定中断的响应顺序；

- 优先级分组：教程使用分组2（抢占优先级2位，响应优先级2位），通过NVIC_PriorityGroupConfig(NVIC_PriorityGroup_2)配置；

- 抢占优先级：数值越小，优先级越高，可打断正在执行的低优先级中断；

- 响应优先级：数值越小，优先级越高，不能打断正在执行的中断，仅当抢占优先级相同时，按响应优先级响应。

3.  标准库配置步骤（3步：GPIO配置→EXTI配置→NVIC配置）：

步骤1：配置GPIO为输入模式（上拉/下拉，如按键中断，配置为上拉输入）；

步骤2：配置EXTI（中断线映射、触发方式、使能中断）；

步骤3：配置NVIC（优先级分组、中断通道、优先级，使能中断通道）。

4.  核心函数与参数：

- EXTI配置函数：

- GPIO_EXTILineConfig(GPIO_PortSourceGPIOA, GPIO_PinSource0); // 将EXTI0映射到PA0

- EXTI_InitTypeDef EXTI_InitStructure; // 定义EXTI结构体

- EXTI_InitStructure.EXTI_Line = EXTI_Line0; // 指定中断线（对应PA0）

- EXTI_InitStructure.EXTI_Mode = EXTI_Mode_Interrupt; // 中断模式（非事件模式）

- EXTI_InitStructure.EXTI_Trigger = EXTI_Trigger_Falling; // 下降沿触发（按键按下时触发）

- EXTI_InitStructure.EXTI_LineCmd = ENABLE; // 使能该中断线

- EXTI_Init(&EXTI_InitStructure); // 初始化EXTI

- NVIC配置函数：

- NVIC_PriorityGroupConfig(NVIC_PriorityGroup_2); // 优先级分组2

- NVIC_InitTypeDef NVIC_InitStructure; // 定义NVIC结构体

- NVIC_InitStructure.NVIC_IRQChannel = EXTI0_IRQn; // 中断通道（对应EXTI0）

- NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 1; // 抢占优先级1

- NVIC_InitStructure.NVIC_IRQChannelSubPriority = 1; // 响应优先级1

- NVIC_InitStructure.NVIC_IRQChannelCmd = ENABLE; // 使能该中断通道

- NVIC_Init(&NVIC_InitStructure); // 初始化NVIC

5.  中断服务函数（教程重点，固定命名，不能修改）：

- 格式：void 中断通道名_IRQHandler(void) { ... }

- 示例（EXTI0中断）：

void EXTI0_IRQHandler(void)

{

if(EXTI_GetITStatus(EXTI_Line0) == SET) // 判断是否是EXTI0中断触发

{

delay_ms(20); // 按键消抖

if(GPIO_ReadInputDataBit(GPIOA, GPIO_Pin_0) == 0) // 再次判断按键是否按下

{

// 中断处理逻辑（如翻转LED电平）

GPIO_WriteBit(GPIOB, GPIO_Pin_0, !GPIO_ReadOutputDataBit(GPIOB, GPIO_Pin_0));

}

EXTI_ClearITPendingBit(EXTI_Line0); // 清除中断标志位（必须做，否则中断会一直触发）

}

}

## 3.4 TIM（定时器，教程中重点外设，三大核心功能）

STM32F103系列定时器分为3类，教程重点讲解「通用定时器（TIM2-TIM4）」，高级定时器（TIM1/TIM8）和基本定时器（TIM6/TIM7）略过。

1.  定时器分类（教程简化版）：

- 通用定时器（TIM2-TIM4）：可实现定时、计数、PWM输出，最常用；

- 高级定时器（TIM1/TIM8）：功能更全，支持互补PWM，用于电机控制，教程不重点讲；

- 基本定时器（TIM6/TIM7）：仅支持定时功能，无PWM和计数，教程不重点讲。

2.  核心原理（定时功能为例）：

- 定时器本质是“递减/递增计数器”，通过配置「预分频系数（PSC）」和「自动重装值（ARR）」，实现精准定时；

- 定时时间计算公式（教程核心公式，必须记住）：

定时时间 = （预分频系数 + 1）×（自动重装值 + 1） / 定时器时钟频率

- 说明：通用定时器挂载在APB1总线上，时钟频率为36MHz（若APB1分频系数为1，时钟频率为72MHz，教程默认36MHz）。

- 示例：定时器时钟36MHz，PSC=35999，ARR=999 → 定时时间 = (35999+1)×(999+1)/36000000 = 1s。

3.  三大核心功能（教程重点，逐个讲解，实战性强）：

### 3.4.1 定时功能（定时器中断，实现精准延时/定时）

配置步骤（4步：时钟使能→TIM初始化→NVIC配置→使能定时器中断）：

步骤1：使能TIM对应总线时钟（TIM2-TIM4属于APB1外设，用RCC_APB1PeriphClockCmd()）；

步骤2：配置TIM初始化结构体（定时模式、预分频系数、自动重装值）；

步骤3：配置NVIC（定时器中断属于中断，需配置优先级）；

步骤4：使能定时器更新中断（TIM_IT_Update），启动定时器（TIM_Cmd()）。

核心函数与示例（TIM2定时1s）：

- 时钟使能：RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM2, ENABLE);

- TIM结构体配置：

### 3.4.2 计数功能（向上/向下计数，实现脉冲计数、测速）

核心思路：将外部脉冲信号接入定时器的计数引脚（如TIM2_CH1=PA0），定时器根据脉冲的上升沿/下降沿计数；

配置重点：在TIM初始化结构体中，将计数模式改为“外部触发计数”，指定触发方式（上升沿/下降沿）；

核心函数：TIM_GetCounter(TIM2); // 读取当前计数器的值，即脉冲个数；

实战应用：测量外部传感器的脉冲个数（如编码器脉冲）、测速（通过单位时间内的脉冲个数计算速度）。

### 3.4.3 PWM输出（脉冲宽度调制，核心应用：电机驱动、LED呼吸灯）

核心原理：PWM是“高低电平交替的脉冲信号”，通过调节「占空比」（高电平时间占周期的比例），实现电压调节；

占空比计算公式：占空比 = 比较值（CCR） / 自动重装值（ARR） × 100%；

示例：ARR=999，CCR=500 → 占空比50%（高电平500us，低电平500us）。

配置步骤（5步：时钟使能→GPIO配置→TIM初始化→PWM模式配置→启动定时器）：

步骤1：使能TIM和GPIO时钟（GPIO为复用推挽输出，对应TIM的PWM引脚）；

步骤2：配置GPIO为“复用推挽输出”（GPIO_Mode_AF_PP），对应TIM的PWM引脚；

步骤3：配置TIM时基参数（PSC、ARR、计数模式）；

步骤4：配置TIM输出比较模式（PWM模式1/2），设置比较值（CCR）；

步骤5：使能TIM输出，启动定时器。

核心函数与示例（TIM3_CH1=PA6，输出PWM控制LED呼吸灯）：

- PWM模式配置：

TIM_OCInitTypeDef TIM_OCInitStructure;

TIM_OCInitStructure.TIM_OCMode = TIM_OCMode_PWM1; // PWM模式1（ARR>CCR时输出高电平）

TIM_OCInitStructure.TIM_OutputState = TIM_OutputState_Enable; // 使能输出

TIM_OCInitStructure.TIM_OCPolarity = TIM_OCPolarity_High; // 输出极性高

TIM_OCInitStructure.TIM_Pulse = 0; // 初始比较值（占空比0%，LED熄灭）

TIM_OC1PreloadConfig(TIM3, TIM_OCPreload_Enable); // 使能PWM预装载

- 占空比调节：通过修改CCR的值调节占空比，如TIM_SetCompare1(TIM3, 500); // 设置CCR为500，占空比50%

实战应用：

- LED呼吸灯：在main函数循环中，逐步增加/减少CCR的值，实现LED亮度渐变；

- 舵机驱动：输出50Hz PWM（周期20ms），通过占空比（0.5ms~2.5ms）控制舵机角度；

- 直流电机驱动：通过占空比调节电机转速。

4.  易错点：

- 定时时间计算错误，未考虑定时器时钟频率；

- PWM输出时，GPIO未配置为复用推挽输出，导致无PWM信号；

- 忘记使能PWM预装载，导致占空比调节无效。

## 3.5 ADC（模拟数字转换器，将模拟信号转换为数字信号）

STM32F103的ADC为12位逐次逼近型，教程重点讲解「单通道单次采样」和「多通道扫描采样」，配合DMA使用（拓展）。

1.  核心概念：

- 模拟信号：连续变化的信号（如电位器的电压、温度传感器的电压）；

- 数字信号：离散的信号（如0~4095，对应0~3.3V电压）；

- 分辨率：12位，即模拟信号转换为数字信号的范围是0~2¹²-1 = 0~4095；

- 参考电压（Vref+）：ADC的基准电压，教程中接3.3V，因此电压计算公式：

实际电压 = （ADC采样值 / 4095） × 3.3V

- 采样时间：ADC采集模拟信号的时间，采样时间越长，精度越高，教程默认配置。
